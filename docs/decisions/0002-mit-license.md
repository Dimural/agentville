# 0002: MIT licence
Status: Proposed
Date: 2026-10-01

## Context
The owner wants Agentville to be open source. The brief suggested MIT as typical.

## Decision
MIT licence for all code and procedurally generated art. A bundled font (if any) keeps its own licence (e.g. OFL), recorded in `THIRD_PARTY.md`.

## Consequences
Maximally permissive. Contributors' code is accepted under MIT (inbound = outbound).
